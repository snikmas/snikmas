For the last 3 years, I've been dreaming about finding a remote job. I started by learning frontend, thinking: _I can do freelance work, build websites, make some money._ [failed. well, skill issue.] Then I started learning backend with Java, hoping to get an internship at one of the big Chinese tech companies. Later, a good friend of mine recommended me for an internship related to Python, Docker, and AI agents, so I started learning all of these things at once (December speedrun: relearn two things I'd already forgotten and learn one completely new thing).

Got an interview. Got the internship. Then my university teachers didn't allow me to go (visa problems). Awesome.

Anyway, that internship got me interested in AI agents, so later I started learning more about agent development. I like both backend and agent stuff, and I'm open to either, but from what I've seen so far, it actually looks like it might be easier to get an internship in an AI agent role right now. The field is relatively new, so maybe there's simply less competition (okay, I could be wrong, but that's my impression for now). Agent development also feels less abstract to me than backend, so somehow I feel like I understand it more easily. YouTubers played a role here too—Theo, for example. I think he probably influenced me the most and made me seriously consider changing my direction. When I first started watching him, he talked a lot and in detail about the main agent concepts: harnesses, tokens, context windows, and so on. I basically stumbled into one of the best AI agent courses by accident.

I kept learning, built a website, worked on projects, made some connections... and then, suddenly, I started getting emails with actual internship opportunities. That's what I wanted, right? So why do I feel... so unsure?

Well. Language.

I can speak English, Chinese, and Russian. One of the reasons I started this blog was to improve my language skills (but also, I just like talking about things, so there's that). But actually using these languages to explain technical things in an interview? Oh. I tried. Turns out that's harder than I expected. A lot of "hm," "so," "um," "this thing," 那个东西, 这个东西, 就是...

It probably doesn't even matter which language it is. Your first interview for a job you genuinely want (and think you could actually do) is always going to be stressful. Even if you speak the language perfectly, stress is stress. Okay, there's one exception: if you don't really expect to get the job, it can actually be pretty exciting. That was my Tencent attempt. I expected absolutely nothing, so I was just having fun. Then I somehow made it to the third interview, and suddenly things weren't so funny anymore.

I think I've been in the "searching/learning" stage for so long that I forgot communication was something I needed to practice too. I kept thinking: learn another framework, build another project, understand another concept. Turns out I also need to practice actually talking about all those things.

So yeah, I wish I had started practicing my languages out loud earlier. Not just reading, writing, or learning technical stuff in them. At some point, I'd like to be able to send an email or explain something in an interview without first thinking, _wait, does this sentence sound normal?_, and opening LLM to check it.
